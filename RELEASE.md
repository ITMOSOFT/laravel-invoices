# GitHub Release: v1.0.0 — Initial Release

**Repository:** `ITMOSOFT/laravel-invoices`

**Description:** Invoice records, line snapshots, numbering and payment tracking for Laravel applications.

## Included
- Invoice records and configurable numbering.
- Invoice items with historical snapshots.
- Subtotal, discount, tax, shipping and total snapshots.
- Issue and due dates.
- Multiple payment records and partial/full payment tracking.
- Invoice status history and events.
- Configurable table prefix.
- PHPUnit tests and GitHub Actions workflow.

## Compatibility
- PHP 8.3+
- Laravel 12 and 13

## Scope exclusions
No PDF generation, email delivery, payment gateway execution, tax calculation, or accounting ledger integration.
